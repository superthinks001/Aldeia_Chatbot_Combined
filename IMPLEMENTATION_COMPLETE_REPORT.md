### 4. ✅ SPECIFIC PDF INFO (Page/Paragraph Numbers)

**Status:** ✅ **FULLY IMPLEMENTED**

**Implementation:**
- **Location:** `apps/chatbot-frontend/src/components/MessageList.tsx` (Lines 124-136, 388-395)
- **Features:**
  - Converts `chunk_index` to estimated page and paragraph numbers
  - Formula: ~5 chunks per page, ~2 chunks per paragraph
  - Displays as "Page X, Paragraph Y" next to source name
  - User-friendly format

**Code:**
```typescript
const getPDFLocation = (chunkIndex: number, source: string): string => {
  const estimatedPage = Math.floor(chunkIndex / 5) + 1;
  const paragraphInPage = Math.floor((chunkIndex % 5) / 2) + 1;
  return `Page ${estimatedPage}, Paragraph ${paragraphInPage}`;
};
```

## CONFIGURATION REQUIRED

### Environment Variables

**Backend (.env):**
```bash
# VAPID keys for push notifications (generate using: npx web-push generate-vapid-keys)
VAPID_PUBLIC_KEY=your_vapid_public_key_here
VAPID_PRIVATE_KEY=your_vapid_private_key_here
VAPID_SUBJECT=mailto:admin@aldeia.com
```

**Frontend (.env):**
```bash
# VAPID public key (same as backend VAPID_PUBLIC_KEY)
REACT_APP_VAPID_PUBLIC_KEY=your_vapid_public_key_here
```

**To Generate VAPID Keys:**
```bash
cd apps/backend
npx web-push generate-vapid-keys
```
